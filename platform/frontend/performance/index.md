# Frontend Performance Output Index

## 範圍

本目錄保存前端效能工具產生的最新報告與 JSON 快照，是測量產物，不是方法規格或長期裁決文件。

## 使用方式

- 先讀 `platform/performance/index.md` 了解正式報告與評分方法入口。
- 使用本目錄資料前檢查檔案時間、Project／Build 版本與產生方式；無法確認時重新執行適用工具，不把「latest」檔名當成新鮮度證明。
- 不手動把生成快照當作唯一效能真相，也不以其推導未測 Project 的效能。

## 權限

若工具會覆寫本目錄輸出，執行前先確認目標檔案與是否保存既有結果；本索引不授權刪除或覆蓋歷史報告。
