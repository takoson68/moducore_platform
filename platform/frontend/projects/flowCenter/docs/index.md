# FlowCenter 文件索引

## 範圍與現況

本目錄包含 FlowCenter 規劃、後端計畫、Phase 狀態與歷史 Gap／反向驗證報告。它們代表不同時間點的提案或狀態紀錄，不保證反映目前程式。

## 閱讀順序

1. 先讀 `platform/frontend/projects/flowCenter/project.config.js` 與本 Project `modules/` 實際功能。
2. 產品／範圍討論時讀 [`FLOWCENTER_PROJECT_PLAN.md`](./FLOWCENTER_PROJECT_PLAN.md)，但其中對平台或新需求的限制需以使用者當前決策及 `_VibeCore/` 規則校正。
3. 要查歷史缺口或階段狀態時，按需閱讀 `FLOWCENTER_GAP_REPORT_*`、`PHASE_STATUS.md`、`BACKEND_PHASE_STATUS.md` 與 Reverse Validation；勿從舊 Status 推定當前狀態。

## 權限

本索引與計畫文件不授權擴大功能、修改平台核心或推送／部署。
