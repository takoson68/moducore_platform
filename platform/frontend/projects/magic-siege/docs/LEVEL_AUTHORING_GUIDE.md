> 用途：新增第 3 關以後的關卡時，複製本文件，完成表格與 Gate，再開始實作。關卡資料必須集中在 `modules/battlefield/maps.js`，不得只在繪圖或 simulation 內另寫一份路線。

目前波數規則：第 1 關 10 波，之後每增加一關增加 3 波（13／16／19／22）。HUD 節點列固定為 10 個視覺節點，進度以節點亮度與目前位置表示，不隨波數增加而拉長。

## 2. 地圖資料必填欄位

在 `maps.js` 新增一筆設定，至少包含：

```js
{
  name: '關卡名稱',
  route: [[起點欄, 起點列], [轉折欄, 轉折列], [終點欄, 終點列]],
  obstacles: [[障礙欄, 障礙列]],
}
```

規則：

- 路線座標必須在目前棋盤範圍內。
- 相鄰路線節點必須是水平或垂直，不可斜角跳躍。
- 起點與終點不可放入障礙物。
- 障礙物不可與道路重疊。
- `mapPathCells(level)` 產生的道路格，必須同時供道路判定、地圖繪製與塔建造限制使用。
- 敵人移動、導引線、傳送門與城堡必須讀同一份 `route`，不可各自硬編。
