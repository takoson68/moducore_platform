# 攻破魔法城｜當前進度

## 2026-10-27 正確性與可擴充性修正（進行中）

- 模擬器新增穩定 `towerId`／`sourceTowerId`，子彈與射線不再依賴塔陣列索引；射線保留發射起點，拆塔後仍可安全結算。
- 一般塔在取得最近目標後持續追蹤，目標失效才重新選擇；魔法射線塔首次選擇最先進入射程的敵人，符合目前塔型規則。
- 出怪改為依累積時間補出多隻敵人，修正卡頓、分頁恢復與大時間差造成的出怪落後。
- 建造合法性集中由 Simulation 的 `cellKind`／`canBuildAt` 判斷，畫面與模擬器共用道路、障礙物與塔格規則。
- battlefield simulation 測試擴充至 22/22，涵蓋穩定塔身分、非法格建造拒絕與大時間差出怪。
