# 攻破魔法城｜下一階段執行里程碑

## 目標

在現有五關最小閉環上，加入可重玩、可比較、可逐步學習的進度系統。音效暫不納入本階段。

## 執行順序總覽

| 里程碑 | 主題 | 目的 | 狀態 |
|---|---|---|---|
| M6 | 通關紀錄保存 | 保留每關最佳成果 | 待執行 |
| M7 | 關卡選擇與解鎖 | 支援自由重玩五關 | 待執行 |
| M8 | 塔升級差異 | 讓升級不只是數值增加 | 待執行 |
| M9 | 新怪物特殊能力 | 建立塔與怪物的克制關係 | 待執行 |
| M10 | 五關教學節奏 | 讓每關逐步介紹新內容 | 待執行 |
| M11 | 結算畫面強化 | 比較本次與歷史最佳 | 待執行 |

## M6｜通關紀錄保存

### 範圍

- 每關保存最高星數、最高分、最快時間、最高擊殺數。
- 重新整理或重新開啟頁面後仍可讀取。
- 新成績只取較佳結果，不覆蓋較差紀錄。

### 驗收 Gate

- 通關後紀錄立即更新。
- 五關各自獨立保存。
- 清除或重開目前關卡不會誤刪歷史最佳。
- 測試涵蓋首次紀錄、刷新讀取與較佳／較差成績比較。

## M7｜關卡選擇與解鎖

### 範圍

- 顯示第 1～5 關、名稱、星數與解鎖狀態。
- 第 1 關預設解鎖；完成上一關後解鎖下一關。
- 已解鎖關卡可自由重玩，未解鎖關卡不可進入。

### 驗收 Gate

- 可從關卡選擇進入任一已解鎖關卡。
- 進入關卡時自動下一波預設關閉。
- 返回選關不遺失通關紀錄。
- 手機畫面可清楚點擊五個關卡卡片。

## M8｜塔升級差異

### 範圍

- 單體塔：升級射程、傷害或攻速。
- 群攻塔：升級範圍、濺射比例或冷卻。
- 右側 UI 顯示升級前後差異。

### 驗收 Gate

- 升級前後至少有一項可觀察行為改變。
- 單體塔與群攻塔的升級路線不同。
- 金幣不足、最高等級與拆除退款規則正確。

## M9｜新怪物特殊能力

### 建議順序

1. 快速怪：低血量、高速度。
2. 盾牌怪：先承受固定護盾傷害。
3. 治療怪：週期性恢復附近怪物生命。

### 驗收 Gate

- 新能力有獨立資料欄位或規則函式。
- 單體塔與群攻塔對新怪物的互動可測試。
- 怪物外觀、血條或提示能在手機畫面辨識。
- 不破壞既有小怪、大怪與 Boss。

## M10｜五關教學節奏

- 第 1 關：只教單體塔與基本波次。
- 第 2 關：介紹群攻塔與密集敵人。
- 第 3 關：混合速度與血量差異。
- 第 4 關：加入特殊怪物。
- 第 5 關：完整混合配置與 Boss 收尾。

### 驗收 Gate

- 每關至少有一個新玩法或策略差異。
- 關卡難度、波數與獎勵在文件中同步。
- 玩家不需要閱讀外部文件才能理解基本操作。

## M11｜結算畫面強化

### 範圍

- 顯示本次分數、星數、時間、擊殺數、剩餘生命。
- 顯示歷史最高分、最高星數、最快時間。
- 新紀錄有明確提示。

### 驗收 Gate

- 沒有歷史紀錄時顯示「首次通關」。
- 成績沒有變好時不誤顯示新紀錄。
- 五關結算資料彼此獨立。

## 每個里程碑的共同流程

1. 先更新企劃與資料欄位。
2. 修改模擬器與 Store。
3. 修改 UI 與手機操作。
4. 補單元測試與必要的整體流程測試。
5. 在正確的 `magic-siege` 本機 Project 驗證。
6. 執行建置與部署前檢查。
7. 建立部署版本並用手機驗收。
8. 回寫 `PROGRESS.md` 與本文件狀態。

## 完成定義

M6～M11 全部通過後，五關版本才視為「可重玩的小型完整版本」；在此之前不擴增第六關，避免內容增加但核心進度系統尚未穩定。
