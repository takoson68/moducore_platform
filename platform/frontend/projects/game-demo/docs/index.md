# game-demo 文件索引

## 範圍

本目錄保存 game-demo 的遊戲設計與試玩說明。它描述遊戲方向，不取代平台 Game Runtime 契約或實際程式。

## 閱讀順序

1. 先讀 [`README.md`](./README.md) 了解目前遊戲畫面與互動設計摘要。
2. Game 容器、生命週期與引擎能力讀 `platform/frontend/src/app/game/index.md` 及其必要子索引。
3. 玩法與畫面現況以 `game-demo/modules/`、`project.config.js` 和測試驗證；設計摘要中宣稱的互動需逐項確認程式是否已落地。

## 權限

此目錄不裁決平台 Game 能力，也不代表遊戲已達完整塔防或發布完成。
