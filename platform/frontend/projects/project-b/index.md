# Project B 執行文件索引

## 範圍

本目錄保存 Project B 前端 Project 實作與少量驗收／功能文件。Project 選擇與平台規則依上層 `platform/frontend/projects/index.md` 和 `_VibeCore/` 正式規範。

## 閱讀順序

1. 先讀 `project.config.js` 與 `modules/index.js` 確認目前組裝清單。
2. Project 特有驗收材料讀 [`VERIFY.md`](./VERIFY.md)，但把它視為建立時的檢查清單，逐項回到現行實作及測試驗證，不視作當前通過證明。
3. 特定模組／樣式依其目錄 index；`mtk2mad`、`styles` 另有局部文件。
4. Auth／Employee API 依 `platform/worker/index.md`、`_VibeCore/api/index.md` 與對應測試交叉核對。

## 權限

驗收清單不授權遠端帳戶、資料庫、Migration 或部署操作。
