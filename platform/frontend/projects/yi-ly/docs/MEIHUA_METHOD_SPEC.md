# 梅花易數第一版方法規格草案

## 1. 文件目的

本文件記錄梅花易數第一版年月日時起卦流程、解讀資料與尚待裁決事項。方法仍是研究草案，尚未完成核准與來源規則登錄；目前已建立前端初版計算服務及方法頁面，不能視為整套方法或解讀流程已完成。

## 2. 方法邊界

- 梅花易數是以數、時、物象等方式取得卦象，再依其象數、體用與五行規則閱讀《周易》的方法。
- 它使用《周易》六十四卦與卦爻辭，但不等同金錢卦，也沒有《焦氏易林》那種 4096 條本卦／之卦詩籤對照庫。
- 現有《周易》資料可供第一版引用；梅花易數新增的是獨立起卦規則、體用判定與解讀流程。
- 《梅花易數》古籍本身包含起卦規則、卦象類別、占例及體用論述。若產品要展示或引用該書原文，須另行建立來源、版本、段落定位與權利紀錄；本草案引用它作規則依據，不等於已匯入語料。
- 金錢卦結果不可事後改標為梅花易數結果。兩種方法共用《周易》原文，但各自保存輸入、規則版本與計算紀錄。

## 3. 建議第一版範圍

第一版只實作「年月日時起卦」，不先提供數字占、字占、聲音占、物數占、外應等入口。這些入口在古籍中各有取數規則，應逐項確認原文與可重現的輸入模型後再加入。

### 3.0 建議採用文本

建議第一版以易學網完整五卷《梅花易數》網頁文字作為**操作規則來源**，只擷取起卦、互卦、體用及直接說明這些規則的占例段落，不整批複製五卷所有分類占斷。易學網明確說明此整理本參校多種版本、校訂疑字並重新句讀，因此資料來源標示必須寫「易學網整理本」，不能標成未經整理的原始轉錄。取卦頁提供年月日時、字占及三數法的可讀網頁說明；占例頁也直接呈現觀梅、牡丹等計算文字，無須下載 PDF、掃描或 OCR。

此選擇代表「依易學網整理本實作一套可追溯、可重現的梅花易數流程」，不宣稱採用最早版本或宋代邵雍定本。易學網另列的單卷《家傳邵康節先生心易卦數／大字梅花心易》視為不同文本，保留作後續版本比較，不與五卷本拼接。來源方向建議採用，但規格仍是草案，未核准或實作。

易學網的取卦說明也提醒，年月日時法會讓同一日、同一時辰的使用者得到同一卦，並指出不同取數設計會改變結果。這是方法特性，不應以追求機率平均為由暗中改寫；第一版若保留年月日時法，應清楚顯示所用時間與算法。其他取數方式留待後續按各自原文另立 profile，不與年月日時規則混算。

### 3.1 時間輸入

由使用者明確選擇或確認起卦時間，並保存時區。介面應說明這是起卦取數時刻，不是事件預計發生的時間；預設使用裝置目前的當地時間，也允許使用者修改。結果同時顯示解析後的農曆年月日、時辰與時區。介面要說明年支、農曆月日與時辰會參與本卦及動爻計算，因此不同時刻可能得到不同卦象。候選底本文字所述年月日時法使用年支、農曆月序、農曆日數及時辰序數；不可只靠瀏覽器語系格式化 API 推算農曆日期。易學網列出的規則沒有明定時區、夏令時間、閏月與子時換日細節，因此以下均標示為產品換算慣例，不稱作原典定論。

前端已鎖定 `lunar-javascript` 1.7.8，僅呼叫公曆／農曆轉換及年支、時支介面；該函式庫聲明無第三方依賴、MIT 授權並支援陽曆與農曆轉換。它包含本產品不需要的術數功能，不得把那些功能帶入結果或解讀。程式已依下方產品慣例轉換年界、閏月、日期與時辰，但這些邊界案例尚未完成逐項核驗，因此依賴已採用，轉換規則仍須經驗證後才能視為發布完成。[專案首頁](https://github.com/6tail/lunar-javascript)、[版本紀錄](https://github.com/6tail/lunar-javascript/releases)

建議的首版換算慣例：

1. 使用者時區採裝置目前的 IANA 時區；以使用者輸入的當地年月日時取值，保存時區識別字，不先轉成 UTC 再取日期。
2. 年支使用農曆正月初一換年的年支，不採八字「立春換年」；月份使用農曆月序，閏月沿用同序月數（例如閏二月仍取 2），不額外加月數。
3. 時辰按十二地支、每支兩小時換算，子時取數 1；23:00–00:59 同屬子時。農曆年月日仍由該當地民用日期換算，因此 23 時段不額外把日期推到次日，00:00 後則使用當天日期。
4. 保存原始當地時間、IANA 時區、轉換後農曆年月日／年支／時支、規則 profile 及轉換器版本。結果頁顯示這些換算值，讓使用者可核對。

這些規則是為了首版結果可重現而提出的產品決策；採用前應用跨農曆年、閏月、子時兩端及時區案例核對轉換器，並在介面說明其慣例。

### 3.2 取數與成卦

依所選底本文字逐步計算並顯示中間值：

1. 年支數：子至亥依序取 1 至 12。
2. 月數：農曆正月至十二月取 1 至 12。
3. 日數：農曆初一至三十取 1 至 30。
4. 時辰數：子至亥依序取 1 至 12。
5. 年、月、日數相加，以除八餘數定上卦。
6. 年、月、日、時數相加，以除八餘數定下卦，並以同一總數除六取動爻。
7. 餘數為零時，卦數取第八卦坤，爻位取第六爻；此規則須作為方法規格明文記錄。
8. 動爻陰陽反轉，產生變卦。爻位由下往上計，確保與本專案易卦 pattern 的 bottom-up 格式一致。

八卦數採來源列示的先天數序：乾一、兌二、離三、震四、巽五、坎六、艮七、坤八。不可將公曆年月日數直接代入，除非另行選定並標示另一種起法。

### 3.3 原典占例的公式對照

易學網《占例篇》所載「觀梅占」提供一組年月日時例：辰年取 5、十二月取 12、十七日取 17，合計 34；34 除八餘 2，取兌為上卦。申時取 9，加總為 43；43 除八餘 3，取離為下卦；43 除六餘 1，取初爻為動爻。這與該頁整理本文字記載的「澤火革」相符。

依六爻由下往上的卦形計算，初爻變後下卦由離變艮，所得變卦為澤山咸；本卦中間四爻取互卦，下互為巽、上互為乾，所得互卦為天風姤。原文並以兌金為體、離火為用，說明用卦剋體的讀法。此例可作演算對照；故事占斷內容不作產品必然預測。

第二組對照採《占例篇》的「牡丹占」：巳年取 6、三月取 3、十六日取 16，上卦總數 25，除八餘 1 為乾；加卯時 4 得 29，下卦除八餘 5 為巽，動爻 29 除六餘 5，為天風姤五爻動、變火風鼎。把姤卦第五爻反轉後，上卦由乾變離，下卦仍為巽，與原文的「姤之鼎」相符。這組例文連同觀梅占，可作年月日時法的兩組演算對照；程式計算結果仍須與來源原文分欄保存。

## 4. 卦象與解讀步驟

### 4.1 本卦、互卦、變卦

- 本卦：年月日時取數所得上下卦組成的六爻卦。
- 互卦：以六爻自下而上編號 1–6；下互卦取第 2、3、4 爻，上互卦取第 3、4、5 爻。易學網五卷本另記「乾坤無互，互其變卦」；若本卦為乾或坤，依此改從變卦取互卦。此條應在程式裡作明確分支，並以乾、坤本卦各一例驗證。
- 變卦：將動爻反轉後所得之卦。
- 呈現時保留三者的卦名、卦畫、上下卦及推導步驟，不把三者說成過去、現在、未來的固定時間牌陣。

已核對的互卦例：觀梅占澤火革取下互巽、上互乾，合為天風姤；牡丹占天風姤取上下互皆乾，合為乾為天。這兩例可用來驗證六爻方向和互卦切片位置。乾、坤特殊分支仍需補例後才能宣稱完成。

### 4.2 體卦、用卦

易學網五卷本的體用論述依動爻區分動靜：三爻皆靜的經卦為體，有動爻的經卦為用。年月日時法只取一動爻，因此動爻所在的經卦作為用卦，另一經卦作為體卦。觀梅占（下卦動）以兌為體、離為用；牡丹占（上卦動）則以巽為體、乾為用，兩個方向的例子均可核對此規則。解讀先顯示體卦、用卦及各自五行，再呈現兩者生、剋、比和關係。

古籍又以本卦為體用主體，互卦、變卦等作為應象，並有「用卦最切、互次之、變卦又次之」的閱讀次序。第一版可將此順序作為透明的資料呈現次序；不得把古籍吉凶語句改寫成本站保證的結果。

該整理本列出「生體則吉、剋體則凶、比和則吉」等傳統判斷語句。若產品要呈現這類結論，必須直接引用對應原文並標明這是該版本的傳統規則；第一版建議先呈現規則關係及原文，不產生個人情境下的必然斷語。

## 5. 與既有語料的關係

- 共用現有《周易》資料：本卦卦辭、相關爻辭、變卦卦辭，以及已收錄的《彖傳》《象傳》《文言》資料。
- 不將傳文自動視作梅花易數專屬解釋，也不預設每種梅花易數規則都需要讀取全部傳文。
- 不自動加入《焦氏易林》詩籤；除非另有清楚的傳統來源與產品決策，梅花易數結果只按其方法規則選取《周易》相關文本。
- 梅花易數原典規則若進入可執行資料，應保存原文片段、來源定位、機器抽取內容、規則版本及 checksum；不可只留人工改寫後的規則摘要。

## 6. 建議結果資料

第一版 `MeihuaResult` 至少保存：

- `methodId` 與 `methodRuleVersion`
- `inputMode`（第一版為 `date_time`）
- 起卦時間、時區、曆法轉換器名稱與版本
- 年支、農曆月、農曆日、時辰及四個取數值
- 上卦、下卦、動爻與除法餘數
- 本卦、互卦（含無互狀態）、變卦
- 體卦、用卦及其五行關係
- 被引用的《周易》 passage IDs，以及所用 corpus version
- 規則來源 ID、段落定位及規則原文引用 ID

此資料與 `IChingCastingResult` 分開，不直接保存或假裝存在三枚銅錢輸入紀錄。

## 7. 尚待確認事項與發布 Gate

前端已有年月日時計算與結果頁初版。以下項目仍須完成，才能把此方法視為符合發布規格：

1. 確認是否接受易學網五卷整理本作第一版操作規則來源；若接受，作者欄以「傳統題邵雍」表述，不把題署直接當作已證實的成書事實。資料須標作「易學網整理本」，完整保留所擷取原文、原網頁、版本與署名，不得宣稱是未經整理的原始轉錄。易學網另有單卷古本，暫不與五卷本合併。
2. 以易學網同一整理本逐段固定年月日時法、餘數為零、互卦與體用規則的來源定位；一般互卦位置已有兩例交叉核對，乾坤無互例仍待補。
3. 已採用 `lunar-javascript` 1.7.8；逐項核對年界、閏月、時辰邊界與子時跨日，確認產品慣例在轉換器上的實際結果。
4. 決定第一版展示哪些卦爻辭，以及是否提供梅花易數原典規則的原文展開。
5. 觀梅占、牡丹占均已核對通過年月日時公式及變卦。易學網自己的占例分析指出，泛用取變爻說明與觀梅占實際採用的總數有差異；年月日時 profile 以專門的「年月日時起例」為規則依據，例文用來交叉檢查，不覆蓋明文公式。
6. 明確區分「原典規則原文」、「程式計算結果」及「使用者／外部 AI 的推論」。

目前程式將兩種卜法放在同層 `methods/coin/` 與 `methods/meihua/` 目錄，各自以 `index.vue` 作為方法入口並在目錄內封裝專屬計算服務；`pages/index.vue` 負責切換，共用語料查詢 API 留在 casting 層。梅花入口已呈現日期時間取數、卦象、體用及共用《周易》讀取結果。此為第一個可執行切片，不代表來源 Gate、完整解讀、歷史保存、外部 AI 複製或日期邊界驗證均已完成。本文件仍是方法草案，不代表已核准發布的解讀 profile。
