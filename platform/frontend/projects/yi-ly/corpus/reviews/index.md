# Corpus Reviews

以下既有 review 是當時的分析紀錄，不是現行入庫 Gate。依 `../../decisions/D007_source-preserving-corpus-import.md`，本專案不進行人工經文校勘；`needs-human-review` 只保留為 parser 當時輸出的狀態。

保存來源匯入、段落切分、原文檢查、導讀自審、授權核對及 release 檢查紀錄。

紀錄需連結來源 ID、revision、passage ID 或 corpus version，並記載檢查者、時間、結果及問題狀態。實驗版可由專案方自行審閱，但不可偽稱為獨立專家審校。
