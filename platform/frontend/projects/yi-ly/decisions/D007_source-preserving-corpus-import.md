# 原典語料不經人工編修

## 決定

- 《周易》與《焦氏易林》從來源擷取到本機資料庫匯入，不由專案人員逐字校訂、改寫或補字。
- 原始來源文字、機器解析文字及來源定位分欄保存；機器解析結果不取代原始內容。
- 允許程式依明確規則計算結構欄位（例如由來源爻標籤推導陰陽爻序），並保留 parser 版本、狀態、來源頁、revision、checksum 及解析 metadata。
- 不以人工校勘作為匯入本機資料庫的前置 Gate。解析疑點以原始標記及機器狀態保留，不由人員在資料內裁決。
- D1 初期為本機資料庫；遠端部署與公開發布另依使用者指示處理。

## 資料完整性與署名

- 每段資料使用穩定 ID；篇內重複序號不得導致漏資料。
- 匯入前後以筆數、卦序、來源定位及 64×64 配對完整度檢查。這些只驗證機械完整性，不代表文本經人工校勘。
- 易林原頁圖示與文字標籤不一致時，兩者及差異旗標並存，不人工修正正文。
- 每筆保留來源名稱、底本／版本、來源連結、授權／權利聲明、checksum 與本站整理聲明。

## 影響

- 本決定取代 D004、資料管線及舊審校紀錄中「人工校勘後才可匯入」的規劃；來源固定、權利資訊及署名要求仍適用。
- Parser 的 `needs-human-review` 是來源解析狀態，不阻擋本機保存；資料庫匯入不得描述成已人工校勘。
- 可用可重跑的 parser／seed 建置本機 D1；本決定不授權遠端寫入或發布。
