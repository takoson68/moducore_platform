# D005_visible-source-attribution.md
## 結果頁可見署名與授權公告

## Decision

- 決定資料來源、版本、修改聲明與授權資訊如何呈現在使用者可見介面。

## Status

- accepted

## Context

- 專案引用維基文庫轉錄及未來可能加入的其他解讀資料。
- 只在資料庫保存來源但不於介面顯示，無法讓使用者辨識內容權利與版本。
- 「版權所有」不適合套用所有內容：古籍原文、第三方轉錄與本站導讀可能具有不同權利狀態。

## Chosen Direction

- 每個結果頁底部必須顯示「資料來源、署名與授權」區塊。
- 每段原文或解讀可開啟自己的詳細來源；頁尾提供當次結果使用來源的彙總公告。
- 公告至少包含資料名稱、作者／編者或貢獻者、來源平台、固定版本連結、授權、本站修改內容及 corpus version。
- 不以籠統的「版權所有」取代實際授權；公有領域、CC BY-SA、本站自有內容及其他授權分開標示。
- 複製給外部 AI、文字分享及匯出結果時，附帶精簡 attribution；詳細版保留可開啟連結。
- Attribution 由 source registry 及 release manifest 自動產生，不在各頁手動貼固定文字。

## Impact

- Source 與 InterpretationProfile 需具備可顯示 attribution 欄位。
- 結果頁、離線模式、分享內容及匯出產物都要通過 attribution 驗收。
- 來源或授權缺漏時，內容不得進入正式 release。

## Example

```text
資料來源、署名與授權
《周易》原文：公有領域
轉錄來源：中文維基文庫《周易》及頁面貢獻者
固定版本：周易 oldid=7907208；各卦頁版本詳見來源
授權：依來源頁標示之 CC BY-SA 條件
本站處理：繁體顯示、內容切段、結構化與必要標點整理；已作修改
資料版本：yi-ly corpus 2026.11.0
本站簡明導讀：本站自行編寫；權利與授權依本站公告
```
