# D006_mvp-content-and-display-scope.md
## MVP 原典範圍、折疊顯示與導讀審校

## Decision

- 決定 MVP 收錄哪些《周易》內容、如何顯示，以及第一版的閱讀視角與審校方式。

## Status

- accepted

## Context

- 使用者希望資料盡量完整，但不希望大量傳文遮蔽核心卦象結果。
- 《彖傳》《象傳》《文言》提供額外詮釋層次，是否採用應由使用者自行判斷。
- 實驗專案第一版需要可執行的內容流程，不宜等待完整外部審校團隊。

## Chosen Direction

- MVP corpus 收錄卦辭、爻辭、乾用九、坤用六、《彖傳》《大象》《小象》及乾坤《文言》。
- 結果頁預設展開核心經文；《彖傳》《象傳》《文言》預設折疊並標明內容種類。
- 使用者自行決定是否展開閱讀，以及是否把折疊內容納入外部 AI Context。
- 第一版預設提供中性「原文通覽」，另有朱熹《易學啟蒙・考變占》選配讀文方式；本站整理的「形勢／變動／趨勢」及 B、C、D 分析式視角保留為後續 Should。
- 實驗版簡明導讀由專案方逐段編寫與自審；每段仍保留 `draft`、`self_reviewed`、`published` 狀態，AI 草稿不可直接發布。
- 使用者最新決定取代舊版 `TAKO` 預設：首筆保存名稱留白且必須輸入；後續預填最近一筆由使用者命名的紀錄名稱。紀錄名稱不是帳號或全域名稱。
- 後端規劃使用 `yi-ly` 專用 Worker 設定與 D1 migrations 邊界；實際資源 ID 在工程階段建立。

## Impact

- Importer 必須把經文、傳文及《文言》切成不同 passage kind。
- 結果頁、離線 package 與 AI Context 需要保存折疊狀態及使用者選取範圍。
- Corpus 驗證需檢查傳文覆蓋範圍，不只檢查 64 卦辭與 384 爻辭。
- 第一版提供原文通覽與考變占選配切換；其他分析式視角的 UI 與文案延後。
