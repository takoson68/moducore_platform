# DineCore Docs

此目錄存放 DineCore 的規格、邊界、進度與工程執行文件。

目前建議閱讀順序：
- `DINECORE_CURRENT_STATE.md`
- `DINECORE_PROGRESS_TRACKER.md`
- `完成項目分類索引.md`
- 與當前開發主題直接相關的規格或契約文件

若要從顧客體驗角度規劃下一步，建議閱讀：
- `點餐系統顧客體驗改進清單.md`
- `顧客體驗改進實作拆解.md`

已完成、已被吸收進實作、或只保留追溯用途的文件，會移入：
- `完成的舊檔案/`

整理原則：
- 仍作為目前工程入口的文件保留在 `docs/`
- 已完成的小階段規劃、草案、拆解、執行書移入 `完成的舊檔案/`
- 已歸檔的完成項目，統一由 `完成項目分類索引.md` 提供分類入口
