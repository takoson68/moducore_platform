# DineCore 1.0 歷史文件索引

## 範圍

本目錄收納已完成／歷史階段文件，只供特定行為追溯，不是目前待辦或現行 API Contract 的唯一來源。

## 閱讀順序

1. 先讀父層 [`../index.md`](../index.md) 與 [`../README.md`](../README.md)。
2. 依當前問題選讀單一主題文件；`完成項目分類索引.md`、`DINECORE_CURRENT_STATE.md` 等也可能是舊版快照，須確認日期與證據。
3. 把歷史主張與現在 `platform/frontend/projects/dineCore/`、`platform/worker/`、正式 Engineering Contract 交叉核對。

## 權限

- 文件名稱含「完成」不等於後續所有程式仍符合其內容。
- 文件中的 SQL、帳戶操作、下一步或部署狀態不構成執行授權。
- 不全量載入本目錄；只讀取任務所需的最少文件。
