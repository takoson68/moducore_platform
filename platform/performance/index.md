# Performance 評估文件索引

## 範圍

本目錄保存平台核心與單一 Project 的效能評分方法、評估結果及其日期快照。報告是特定版本／環境的觀測，不代表目前 Build 的即時效能。

## 閱讀路由

- 需要選擇或理解評分方法：先讀 [`效能評分模式選擇器.md`](./效能評分模式選擇器.md)。
- 平台核心評估：讀最新適用的 `平台核心效能評分*.md`，並核對報告日期與其測試方法。
- 單一 Project 評估：讀目標 `單一專案效能評分*.md`；不要把 dineCore 報告外推為其他 Project 結果。
- 前端最近一次產出的原始快照位於 `platform/frontend/performance/`，僅作測量輸出，須核對生成時間與對應程式版本。

## 權限與裁決

- 本索引與報告不構成效能 SLO、架構規則或部署 Gate，除非正式 Engineering Contract 明確引用。
- 比較前須確認同一 Project、同一 Build 條件與可比設備；舊快照不可替代重新測量。
