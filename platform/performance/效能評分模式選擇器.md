# Codex 任務：效能評分模式選擇器

你現在要先判斷本次任務屬於哪一種，再執行對應評分：

1. Platform Performance Score
2. Project Performance Score

---

## 判斷規則

### 若使用者提到以下內容，走 Platform Performance Score：
- 平台核心
- container
- module runtime
- store factory
- router registration
- shared runtime
- 平台架構健康度
- 平台可擴展性
- 多專案隔離

### 若使用者提到以下內容，走 Project Performance Score：
- 指定專案名稱
- bundle 太大
- 首屏過慢
- 某模組太肥
- 圖片/字型/第三方依賴太重
- targetProject 的頁面效能

---

## 輸出要求
1. 先回答本次屬於哪種模式
2. 說明判斷原因
3. 再執行對應報告
4. 不可混合評分
