# 覆蓋資料庫流程（Windows 匯出 -> macOS 匯入）

## 1）在 Windows 匯出

```powershell
$out='F:\GitHub\moducore_platform\_workspace\dinecore_full_2026-03-05.sql'
if (Test-Path $out) { Remove-Item $out -Force }
C:\xampp\mysql\bin\mysqldump.exe -u root -proot --routines --triggers --single-transaction moducore_platform --result-file=$out
```

輸出檔案：

- `F:\GitHub\moducore_platform\_workspace\dinecore_full_2026-03-05.sql`

把此檔案帶到 Mac（AirDrop／雲端硬碟／USB 皆可）。

---

## 2）在 macOS 匯入

若檔案放在 `~/Downloads`：

```bash
mysql -u root -p moducore_platform < ~/Downloads/dinecore_full_2026-03-05.sql
```

若密碼是 `root`：

```bash
mysql -u root -proot moducore_platform < ~/Downloads/dinecore_full_2026-03-05.sql
```

---

## 3）匯入後驗證（macOS）

```bash
mysql -u root -p -D moducore_platform -e "SHOW COLUMNS FROM dinecore_table_sessions LIKE 'guest_state_json';"
mysql -u root -p -D moducore_platform -e "SELECT id, table_code, order_id, status FROM dinecore_table_sessions ORDER BY id DESC LIMIT 10;"
```
