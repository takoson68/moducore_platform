# 多框架容器架構想法索引

## 範圍與狀態

本目錄保存關於 Store／Container 在多框架環境適配的探索性想法。內容尚未因此成為已核准需求、World 規則或工程 Contract。

## 閱讀路由

- 需要了解原始想法時讀 [`store 架構在多框架環境中的適配策略.md`](./%20store%20架構在多框架環境中的適配策略.md)。
- 若評估是否採納，先核對 `_VibeCore/world/index.md`、`_VibeCore/core/index.md`、`_VibeCore/engineering/index.md` 與目前 Container 原始碼，再依 Discussions／Change Protocol 取得所需裁決。

## 權限

此目錄是非正式草稿，不能用來推翻現行 Store／Container 行為，也不直接授權重構或建立多框架抽象。
