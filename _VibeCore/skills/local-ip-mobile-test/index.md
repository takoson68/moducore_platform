# Local IP Mobile Test Skill 索引

## 範圍

本 Skill 協助在使用者要求時，讓同一可信任區域網路的手機／平板連到本機測試服務。

## 閱讀順序

1. 先讀 [`../index.md`](../index.md) 與 [`SKILL.md`](./SKILL.md)。
2. 確認服務種類、連接埠、LAN 範圍與可能的防火牆暴露；只在受信任網路啟動必要服務。
3. 優先使用專案目前的 Vite／Worker 本機測試方式，不因 Skill 內 PHP 範例而假設應啟動舊後端。

## 權限

只在使用者要求裝置本機測試時才綁定 LAN 介面；測完停止服務，不將本機服務公開到網際網路。
