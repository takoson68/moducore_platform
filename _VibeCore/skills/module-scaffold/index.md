# Module Scaffold Skill 索引

## 範圍

本 Skill 協助建立或補齊前端 Project Module 的工程骨架。

## 閱讀順序

1. 先讀 [`../index.md`](../index.md) 與 [`SKILL.md`](./SKILL.md)。
2. 依 SKILL 指示讀 `_VibeCore/engineering/MODULE_TEMPLATE_CONTRACT.md`、`CONVENTIONS.md`。
3. 進入目標 Project 前讀 `_VibeCore/projects/index.md`、`platform/frontend/projects/index.md`，再檢查該 Project 現有 Module 風格。

## 權限

Skill 是可重用策略，不裁決 Module 語意、不授權修改共享平台或其他 Project；跨界需求須依正式規範處理。
