# Candidate Boundaries 索引

## 範圍

本目錄保存平台邊界觀察與候選邊界文件。文件可能有 active/candidate 標記，但是否可用仍由父層 `new_engineering/index.md` 白名單裁定。

## 閱讀順序

1. 先讀 [`../index.md`](../index.md)。
2. 只有任務明確涉及平台／Project、Module discovery 或 World-first 邊界，且父索引允許引用時，再讀相應 `B00*.md`。

## 權限

本目錄不取代 `_VibeCore/world/` 或 `_VibeCore/engineering/`；候選內容不得直接當成正式規則或實作授權。
